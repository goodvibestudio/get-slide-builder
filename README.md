# Slide Builder

**Build decks with your agent.**

Slide Builder is a local workspace for HTML slide decks. Bring your own coding agent to draft or revise a deck, then edit text, arrange slides, and leave notes in Slide Builder.

- Start with a template, open an HTML deck, or use your agent to convert a PowerPoint or PDF.
- Edit words directly, duplicate and reorder slides, and save reusable slides to your Library.
- Leave notes for your agent, review its changes, and present in HTML or export a PDF.

## Get the app

**[Download for Mac or Windows](https://goodvibestudio.github.io/get-slide-builder/)**

Free to download. No Slide Builder account required. Use Chrome or Edge for editing; your coding agent runs separately.

The [website](https://goodvibestudio.github.io/get-slide-builder/) has a demo, getting-started instructions, and help. This repository hosts the download site and packaged releases.
